## FAQ Section

### Headline

```
Frequently asked questions
```

**Q: Is it really free?**

```
A: Yes, completely free. No hidden costs, no premium tiers, no "free trial." Free forever.

We're not trying to upsell you. This is a passion project, open-sourced for everyone.
```

**Q: How do you make money then?**

```
A: We don't! This is open source and community-driven.

If you want to support development, star us on GitHub or contribute code. That's worth more than money.
```

**Q: Where is my data stored?**

```
A: In your browser's local storage. We don't have servers. Your data never leaves your device.

Pros: Complete privacy, works offline, lightning fast
Cons: Clearing browser data will delete your boards (export feature coming soon!)
```

**Q: Can I use this with my team?**

```
A: Currently, it's best for individual use or co-located teams (sharing a screen).

Real-time collaboration features are on the roadmap, but we're being thoughtful about adding them without compromising privacy.
```

**Q: What browsers are supported?**

```
A: All modern browsers: Chrome, Firefox, Safari, Edge.

Local storage is a web standard supported everywhere. If you can browse the web, you can use this.
```

**Q: Can I self-host it?**

```
A: Absolutely! It's open source. Clone the repo, run `npm install && npm run dev`, and you're good to go.

Full deployment instructions in the GitHub README.
```

**Q: What if I want to move my data to another device?**

```
A: We're building an export/import feature (coming very soon!).

For now, you can recreate your boards or use the same browser on different devices.
```

**Q: Is this better than [insert tool]?**

```
A: Different, not necessarily better.

We're built for people who want simplicity, privacy, and zero friction. If you need advanced team features, integrations, or enterprise support, stick with established tools.

If you just want a beautiful Kanban board that works instantly - we're perfect.
```

## Key Messaging Principles

### Voice & Tone

- **Confident but humble**: We're good, but we know we're not for everyone
- **Honest**: Acknowledge limitations, don't oversell
- **Friendly**: Conversational, not corporate
- **Empowering**: You're in control, not us

### Word Choices

✅ Use: Simple, Beautiful, Fast, Private, Free, Yours
❌ Avoid: Enterprise, Synergy, Leverage, Disruptive, Revolutionary

### Length Guidelines

- Headlines: 5-10 words max
- Subheadlines: 10-20 words max
- Body copy: 20-50 words max (people scan, not read)
- CTAs: 2-4 words (action-oriented)

## Conversion Optimization Elements

### Above the Fold

- Clear value proposition in 5 seconds or less
- Prominent CTA (high contrast)
- Visual proof (screenshot/demo)
- Trust signals (stats, open source badge)

### Friction Reducers

- Emphasize "No signup required" everywhere
- Show privacy commitment
- Transparent pricing (free!)
- Quick demo video (under 2 min)

### Urgency (Subtle)

- "Join 15,000+ users"
- "Featured on Product Hunt"
- "Trending on GitHub"

### Exit Intent Popup (Optional)

```
Headline: Wait! One more thing...
Copy: Join 5,000+ subscribers for productivity tips and updates.
CTA: Get weekly tips
```

## Mobile Considerations

### Mobile Hero

- Headline: 2rem (32px)
- Subheadline: 1.125rem (18px)
- CTA: Full width on mobile
- Demo: Portrait-oriented screenshot

### Mobile Navigation

- Sticky header with CTA
- Hamburger menu for links
- Tap targets: 44px minimum

### Mobile Sections

- Single column layouts
- Reduce padding to 60px vertical
- Larger touch targets for CTAs
